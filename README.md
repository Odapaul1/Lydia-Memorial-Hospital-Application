# Lydia Memorial Hospital website

A responsive, accessible React website for Lydia Memorial Hospital (LMH), styled after the supplied hospital-site reference and populated with details from `LydiaMemorialWebsitescript.docx`. The homepage retains LMH's supplied hero image and content, with an accessible three-slide carousel, current section links, hospital milestones, founder profile, visitor FAQs and contact information.

## Development

- `pnpm install` installs the pinned dependencies.
- `pnpm dev` serves the site on port 3000.
- `pnpm run build` runs strict TypeScript checking and creates the static site in `dist/`.

## Content and imagery

Hospital history, contact information, described facilities, initiatives and the founder biography are based on information supplied by Lydia Memorial Hospital; they are not independently verified. The site advises visitors to confirm current service availability and eligibility directly with the hospital. The hospital exterior image supplied for the homepage is presented as an illustration. Other photographs are illustrative assets reused from the visual reference and are not represented as images of Lydia Memorial Hospital, its facilities or its staff.
